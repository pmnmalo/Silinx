# Silinx: the user's guide

English · [Português](../pt/README.md)

Silinx is an FPGA design environment for teaching digital systems. These pages show what it does, one subject each.

1. [What Silinx is](what-is-silinx.md): for whom, the two interfaces, where it runs.
2. [Getting started](getting-started.md): open it in the browser or install it, step by step.
3. [Designing](designing.md): VHDL and Verilog, schematics, state machines, ASM charts, Boolean algebra, C.
4. [Circuits on a breadboard](circuits.md): 74xx and 4000 chips wired as on the bench, simulated live.
5. [Simulating](simulating.md): test benches, the waveforms, Try it.
6. [The Board Emulator](emulator.md): the design running on a picture of the board.
7. [Boards and toolchains](boards.md): building for a real board and programming it.
8. [Teaching with Silinx](teaching.md): guided labs, exercises graded automatically, sharing, GitHub.
9. [Silinx for an AI assistant](ai-mcp.md): the MCP server.
10. [Questions and answers](faq.md).

For reference: [every feature](features.md), in detail, and [the toolchains](toolchains.md) (the Silinx toolchain,
Xilinx ISE 14.7, AMD Vivado, programming the board).
