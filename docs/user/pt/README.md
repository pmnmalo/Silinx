# Silinx: o guia do utilizador

[English](../en/README.md) · Português

O Silinx é um ambiente de projeto para FPGA feito para ensinar sistemas digitais. Estas páginas mostram o que faz,
um assunto de cada vez.

1. [O que é o Silinx](what-is-silinx.md): para quem é, as duas interfaces, onde corre.
2. [Começar](getting-started.md): abri-lo no browser ou instalá-lo, passo a passo.
3. [Projetar](designing.md): VHDL e Verilog, esquemáticos, máquinas de estados, fluxogramas ASM, álgebra de Boole, C.
4. [Simular](simulating.md): bancadas de teste, as formas de onda, o Experimentar.
5. [O Emulador da Placa](emulator.md): o projeto a correr numa imagem da placa.
6. [Placas e ferramentas](boards.md): implementar para uma placa real e programá-la.
7. [Ensinar com o Silinx](teaching.md): laboratórios guiados, exercícios avaliados automaticamente, partilha, GitHub.
8. [O Silinx num assistente de IA](ai-mcp.md): o servidor MCP.
9. [Perguntas e respostas](faq.md).
