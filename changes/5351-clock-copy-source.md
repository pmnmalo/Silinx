In short:
- Check Syntax no longer says a clock input copied as it is (`clk <= clk_i;`, `assign clk = clk_i;`) is "generated by logic".

In detail:
- The data-as-clock check follows a concurrent assignment that copies a signal as it is to the copy's source, as a port connection's (core/lint-design.js): a clock input renamed, as light8080's mcu80_uart does, is the clock input, the same copy #5112 stopped calling clock-as-data; a clock made by logic is still warned. The design corpus's light8080 loses its 11 such warnings (#5351).
